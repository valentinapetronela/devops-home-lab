# DevOps Home Lab

A hands-on DevOps and Linux administration project.

## Environment
- OS: Red Hat Enterprise Linux 10.2
- Virtualization: VMware Workstation
- Domain: valentina-practice.online
- DNS provider: Cloudflare

## Learning goals
- Linux administration and RHCSA
- Networking and DNS
- Apache and application servers
- Git and GitHub
- Bash scripting
- Ansible automation
- Docker and Kubernetes
- AWS cloud infrastructure
